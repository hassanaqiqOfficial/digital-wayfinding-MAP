# BWI Marshall Airport Digital Wayfinding Map

Whether one is a regular traveler at BWI Marshall Airport or visiting for the first time, our **real-time data-driven digital wayfinding map** helps ensure a low-stress and enjoyable travel experience.  

This project is a **game-changer interactive PDF-based digital map** built for digital gadgets, designed to guide passengers seamlessly across the airport.  

🔗 **Live Map:** [BWI Wayfinding Map](https://bwiairport.com/wayfinding/)

---

## 🚀 Features
- **Real-time data-driven navigation** across airport facilities.  
- **PDF-based interactive map** optimized for mobile and desktop devices.  
- **Intuitive, low-stress wayfinding experience** for travelers.  
- **Dynamic, responsive UI** for seamless usage.

⚙️ Installation & Setup

Clone the repository:

git clone https://github.com/your-username/bwi-wayfinding-map.git


Navigate into the project directory:

cd bwi-wayfinding-map


Open index.html in your browser or use a local server for development.
Example with Python:

python3 -m http.server 8080

📌 Usage

Use interactive elements to search and navigate airport facilities.
